Privacy policy

Effective date: 12 October 2026

OmniBot L2 Backup is a private, owner-operated utility. This policy describes its Google Drive data use and these public information pages.

Data accessed and purpose

With the owner's authorization, the utility creates and reads archive files and backup-verification metadata in the owner's Google Drive. It uses file contents, names, sizes, identifiers, and checksums only to perform and verify backups and support owner-controlled recovery and retention.

The requested Google scope is https://www.googleapis.com/auth/drive.file. No access to Gmail or Contacts is requested. The utility does not need exchange API keys to back up these files.

Storage and protection

Backup files are stored in the owner's Google Drive. Authorization credentials and local verification records are stored on the owner's controlled system with restricted access. Credentials and private backup contents are not included in this public website or its repository.

Sharing and other uses

The utility does not sell Google user data, use it for advertising, share it with advertisers, or use it to train AI models. Transfers to Google Drive are part of the backup function requested by the owner. Files are not made public by the backup process.

Google processes data under its applicable terms and privacy policy. Access controlled separately by the account owner, such as sharing a Drive folder, remains the owner's choice.

Retention, deletion, and revocation

The owner controls backup retention. Verified local archive copies may be removed according to the configured local retention policy; that does not automatically delete the cloud history. The owner can delete cloud backup files in Google Drive and revoke this application's access in Google Account settings. Revocation prevents further authorized backup operations; it does not automatically erase existing backup files.

This website

These pages use no analytics scripts, tracking cookies, forms, or embedded third-party content. They do not accept private files or credentials. GitHub Pages hosts the website and may process ordinary network request information as described in the GitHub privacy statement.

Contact and changes

For non-confidential questions about these pages, use the public information repository's issues. Never include credentials, private archives, personal account details, or trading records. Material changes to these described practices will be reflected on this page with an updated effective date.
